# CyberSaarthi — Frontend

React + Vite + TypeScript application for CyberSaarthi.

## Scripts
- `npm run dev`: Start the development server on `http://localhost:5173` (proxies `/api` to `http://localhost:5000`)
- `npm run build`: Type-check with `tsc` and bundle with `vite build`
- `npm run preview`: Preview the production build

## Key Modules
- `src/modes/kids`: Interactive story game and mascot for children
- `src/modes/seniors`: High-contrast, large-button, voice-assisted UI in Kannada, Hindi, and English
- `src/modes/adults`: Professional cybersecurity analysis console
- `src/modes/caretaker`: Caretaker management of wards and real-time alerts
- `src/i18n`: Internationalization resource files (`en.json`, `kn.json`, `hi.json`)
